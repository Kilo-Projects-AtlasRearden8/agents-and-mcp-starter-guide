# Master Checklist: AI Agents & MCP

Print this out or copy it into your notes. Check each box as you finish it.

## Part 1: Understand what agents do

- [ ] I can explain, in my own words, the difference between a chatbot and an agent
- [ ] I can name one thing an agent can do that a plain chatbot cannot
- [ ] I know that agents can make mistakes and need a person in charge

## Part 2: Understand how MCP works

- [ ] I can explain what MCP stands for (Model Context Protocol)
- [ ] I can name the three parts of an MCP setup: AI client, MCP server, local resource
- [ ] I understand that stdio means the server runs on my own computer

## Part 3: Run your first stdio server

- [ ] I created a practice folder with harmless files
- [ ] I installed an MCP stdio server (for example, the filesystem server)
- [ ] I connected my AI client to the server
- [ ] I asked the AI to list and read files in my practice folder
- [ ] I confirmed my files stayed on my computer

## Part 4: Follow the safety rules

- [ ] I only gave the server access to one practice folder
- [ ] No passwords or API keys are in that folder
- [ ] I know who made the server and I trust them
- [ ] I know how to stop the server and remove its access

## You are done

When every box is checked, you have run your first MCP server and you know the basics of AI agents and file safety. From here, you can explore more MCP servers, build simple agents, or read the rest of *The Massive AI Manual*.
