# AI Agents & MCP: A Beginner's Manual

A plain-English, step-by-step guide to AI agents and the Model Context Protocol (MCP), written for Dylan Asdale's hub site **dylanasdale.github.io** and published by **Asdale Dynamics, LLC**.

## What this is

This folder contains two versions of the same beginner manual:

- **docs/** — Markdown source files you can read on GitHub or in any text editor.
- **site/** — A static HTML website you can open in any browser, no internet required after download.

Neither version requires you to write code. Every step is written as a checklist you can follow by copying and pasting.

## What you'll learn

- What AI agents do, in plain English
- How MCP servers connect AI to local files and tools on your computer
- How to run your first MCP server over stdio
- Safety rules for giving AI access to your files
